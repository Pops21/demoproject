User Guide

HTML to UMG, in three steps.

Convert any HTML/CSS design into an Unreal Engine 5 UMG Widget Blueprint — paste your markup, generate a package, and import it into your project with the companion plugin.

What you get

The Widget Generator is split into two parts: a web converter that turns HTML into a JSON description plus baked textures, and an Unreal Engine plugin that imports that package and creates the Widget Blueprint inside your project.

🌐Web Converter

Runs entirely in your browser. Paste HTML, tweak a few toggles, get a JSON package with all textures.

🎮UE5 Plugin

Imports the package and rebuilds the layout as a real Widget Blueprint with proper UMG hierarchy.

1Convert your HTML

Open the converter page in any modern browser (Chrome, Edge, or Firefox recommended).

  1. Load your design Paste HTML into the left panel, click File to open a local .html file, or click Example to try a sample. If your HTML references local images, the file picker preserves those references automatically.
  2. Pick a target resolution Use the Resolution dropdown in the top bar — common UE viewport sizes are pre-set (1080p, 720p, 1440p, 4K) plus a Custom option. The HTML is rendered at this exact size and all UMG coordinates use it as the canvas.
  3. Choose what to bake Three toggles control how decorative effects are exported: Shadows bakes box-shadow into textures, Gradients rasterizes CSS gradients as PNGs, and Font Icons turns icon-font glyphs and emoji into image textures (recommended ON if your design uses FontAwesome, Material Icons, or emoji — Unreal's default fonts won't have those glyphs).
  4. Generate Click ⚡ Generate Widget. The right panel shows the UMG widget text, and a Textures & Images section lists every baked asset. The Live Preview on the left lets you confirm what the converter actually rendered.

Tip — If a font, icon, or background image looks wrong in the preview, fix it in the HTML first and regenerate. The preview is exactly what the converter sees.

2Export the package

You have three export options depending on how you want to import:

📦JSON Package

Single ZIP containing the JSON description plus every baked texture in their final folder structure. Recommended for the plugin.

📋Copy

Copies the raw UMG widget text to your clipboard. Paste directly into Unreal Editor's Widget Blueprint graph (textures must already exist).

💾Download

Saves the UMG widget text as a .txt file — useful for review or sharing.

⬇Textures ZIP

Just the textures, no JSON. Useful if you only need to refresh image assets in an already-imported widget.

Recommended flow — Use 📦 JSON Package. The plugin reads it directly and places every texture at the correct path without manual setup.

3Import into Unreal Engine

The companion Widget Creator Pops plugin reads the JSON Package you exported in step 2, imports every texture into your project, and generates a real UWidgetBlueprint — anchors, slots, brushes, fonts, button states and all.

Get the plugin Available on Fab — open the listing and add it to your library, then install it to your engine version from Epic Games Launcher → Library → Fab.

Install & enable

  1. Add to your engine From Fab, install the plugin into Unreal Engine 5.1+. It becomes available to every project that uses that engine version. Editor-only, Windows 64-bit.
  2. Enable it in your project Open your project and go to Edit → Plugins. Search for Widget Creator Pops, tick the Enabled checkbox, then restart the editor when prompted.
  3. Find the toolbar button After restart, look at the Level Editor toolbar — a new Widget Generator button appears next to the Play controls. Click it to open the import window.

Run the import

  1. Pick your source file The window has two tabs: 📦 ZIP Package (recommended — bundles JSON + every texture) and � JSON only (use this if your textures are already in the project). Click Browse… and select the file you exported in step 2.
  2. Map your fonts The plugin scans the JSON for every fontFamily reference and shows a font-mapping dialog. For each family, pick a UFont asset from your project (or accept the default /Engine/EngineFonts/Roboto fallback). Mapping once per font family covers every text widget that uses it.
  3. Choose the destination Set the Asset Name (e.g. WBP_MainMenu) and the Package Path (defaults to /Game/AutoCreated). Textures land at the suggestedPath values baked into the JSON, typically /Game/UI/Textures/….
  4. Click Create The plugin extracts the ZIP in-process, imports each PNG with UI-optimized settings (LODGroup=UI, no mipmaps, sRGB on), waits for texture compilation, then constructs the Widget Blueprint. A dialog confirms when it finishes and offers to open the new asset.

Re-importing — Running the importer again over the same asset path is safe. Existing textures are reused (not destroyed), so any Widget Blueprints already referencing them keep working without breakage.

Verify the generated widget

  • Open your new UWidgetBlueprint — the Designer tab shows the rebuilt UMG hierarchy: a root CanvasPanel (or a ScrollBox for tall pages) with every widget placed at its measured position.
  • Check the textures — in the Content Browser, navigate to /Game/UI/Textures/ to confirm imported PNGs. Each is set to TC_Default, sRGB, NoMipmaps, NeverStream.
  • Resize handle — page backgrounds and edge-touching elements use stretch anchors, so the layout adapts when you change viewport resolution.
  • Need to tweak? The blueprint is yours — rename widgets, hook up button OnClicked events, bind text values, replace placeholder fonts. The plugin doesn't lock anything.

What works well

  • Layouts — CSS positioning (absolute, relative, flex, grid) is flattened to a UMG Canvas Panel with absolute offsets.
  • Text — Fonts, weights, colors, alignment, letter-spacing, line-height, and text-shadow all transfer.
  • Backgrounds — Solid colors, linear/radial/conic gradients, and url(...) images become textures.
  • Borders & corners — Rounded corners use UE's RoundedBox; complex frame borders bake as 9-slice textures.
  • Icons & emoji — FontAwesome / Material / Lucide / Heroicons / Phosphor / Boxicons all detected; standalone decorative glyphs (★ ⚔ ☠ ✦) bake as images.
  • Inline SVG — Rasterized to PNG textures with all CSS styling applied.
  • Inputs & controls — <input> → EditableTextBox, <select> → ComboBoxString, <button> → Button widget, scrollable areas → ScrollBox.

What doesn't transfer

  • Animations — CSS transition and @keyframes are not exported.
  • Rich text formatting — Mixed bold/italic spans inside one paragraph collapse into a single TextBlock.
  • Video / canvas — <video> and <canvas> are not supported.
  • Interactive states — CSS :hover / :active styles aren't captured; static appearance only.
  • Inset shadows — CSS inset shadows have no UMG equivalent and are dropped.

Privacy

The web converter runs entirely in your browser. Your HTML, assets, and generated output never leave your machine — there is no upload, no analytics, and no server-side processing.

Browser rendering note

The converter relies on your browser's layout engine to measure positions and rasterize gradients/shadows/SVG. Output may differ very slightly between browsers (mostly in sub-pixel font rendering). For the most consistent results use the same browser version across your team.
